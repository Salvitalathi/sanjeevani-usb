संजीवनी RESCUE USB
==================
निर्मिती : Mangesh Salvi
एका pendrive वर free आणि legal toolkit: rescue tools चा boot menu + PC Doctor
(PC तपासणी, आपोआप दुरुस्ती, वेग वाढवणे, Assistant). English / मराठी / हिन्दी.

Pendrive तयार करणे
1. ही zip extract करा (right-click > Extract All).
2. 64 GB pendrive लावा (offline driver packs हवे असतील तर 256 GB).
   त्यातला सगळा DATA पुसला जाईल.
3. SETUP.cmd वर double-click करा आणि Administrator परवानगी द्या.
4. भाषा निवडा (English / मराठी / हिन्दी).
5. Pendrive चा Disk number टाका, नंतर ERASE टाइप करा.
6. Downloads होऊ द्या (internet नुसार 30 मिनिटे ते 2 तास).

वापर
- Windows मध्ये: USB उघडा आणि START-Sanjeevani.cmd वर double-click करा (PC Doctor).
  Assistant मध्ये समस्या लिहा - तो PC तपासून आपोआप दुरुस्त करतो.
- Windows सुरू होत नसेल: Boot Menu key (F12 / F9 / Esc ...) दाबून USB निवडा,
  मग Hiren's BootCD PE > PCDoctor-Rescue.cmd.
- पूर्ण मार्गदर्शक: USB वरील "READ-ME - मार्गदर्शक.html" (kit\Sanjeevani\Docs\guide-mr.html).

नंतर
- Update:  <USB>\Sanjeevani\Setup\UPDATE.cmd
- Pendrive भरला: CLEAN.cmd (आधी यादी दाखवतो, तुम्ही हो म्हटल्यावरच काढतो)
- स्वतःचे apps: <USB>\MyTools मध्ये copy करा    दुसरे OS / ISO files: <USB>\ISO

USB वरील folders
  ventoy\        boot menu theme + ventoy.json
  ISO\           bootable rescue images (स्वतःच्या .iso इथे ठेवा)
  Tools\         portable Windows tools (लपवलेले - PC Doctor च्या Tools मार्गदर्शक मधून वापरा)
  Installers\    installers (7-Zip, Malwarebytes ...) (लपवलेले)
  MyTools\       तुमचे स्वतःचे apps
  Sanjeevani\    PC Doctor, docs, tools यादी, setup
  Reports\       PC Doctor reports (प्रत्येक PC चा वेगळा folder)
