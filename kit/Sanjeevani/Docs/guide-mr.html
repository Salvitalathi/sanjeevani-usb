संजीवनी Rescue USB

PC तपासणी, दुरुस्ती आणि वेग वाढवण्याचा pendrive · फक्त free आणि legal tools

1. Pendrive तयार करणे

  1. 64 GB USB 3.x pendrive घ्या (offline driver packs हवे असतील तर 256 GB). त्यातील सगळा data पुसला जाईल.
  2. Kit ची zip file extract करा (right-click → Extract All).
  3. SETUP.cmd वर double-click करा आणि Administrator परवानगी द्या.
  4. Pendrive चा Disk number टाका, नंतर ERASE टाइप करा.
  5. Windows 11 ISO (7.5 GB) आणि Linux Mint (3 GB) हवे का ते विचारले जाईल.
  6. Internet speed नुसार 30 मिनिटे ते 2 तास लागतात. शेवटी काही tools हाताने download करायचे असतील तर त्यांची यादी (manual-downloads) आपोआप उघडेल.

Update: नंतर कधीही pendrive वरील Sanjeevani\Setup\UPDATE.cmd चालवा. फक्त नवीन versions download होतात आणि data पुसला जात नाही.

2. Pendrive वरून boot करणे

  1. PC बंद करा आणि pendrive लावा.
  2. Power दाबताच Boot Menu key दाबत राहा (HP F9, Dell F12, Lenovo F12, Asus Esc...). पूर्ण यादी boot-keys.html मध्ये आहे.
  3. संजीवनी menu दिसेल. ↑ ↓ ने tool निवडा आणि Enter दाबा. प्रत्येक tool ची माहिती खाली दिसते.
  4. Secure Boot error आला तर boot-keys.html मधील "Enroll key" पायऱ्या करा. हे एकदाच करावे लागते.

4. PC Doctor (Windows चालू असताना)

Pendrive उघडा आणि START-Sanjeevani.cmd वर double-click करा (Admin परवानगी द्या).

  • तपासणी: Quick Scan (2 मिनिटे) किंवा Deep Scan (system files सह). यात health score आणि सापडलेल्या समस्या दिसतात, आणि प्रत्येक समस्येपुढे "दुरुस्त करा" बटण असते.
  • One-Click Optimize: restore point → cleanup → अनावश्यक startup बंद → हलके effects → power plan → ads/bloatware काढणे → report.
  • दुरुस्ती: DISM + SFC (खराब system files), disk check, Windows Update reset, Internet reset, Defender आणि drivers.
  • वेग वाढवा: startup programs, tweaks, bloatware. सर्व बदल Undo करता येतात.
  • C: drive जागा: Desktop, Documents, Downloads, Photos आणि C:\ मधले स्वतःचे folders दुसऱ्या drive वर हलवा. दुसरा drive नसेल तर C: लहान करून नवीन DATA drive बनवता येतो.
  • सल्ला: Windows 11 चालेल का, या PC ला कोणते OS योग्य, कोणते apps काढावेत आणि त्यांचे हलके पर्याय कोणते, RAM/SSD upgrade.
  • Tools मार्गदर्शक: 60+ tools - प्रत्येक tool काय करतो, कधी आणि कसा वापरायचा (मराठी / English), धोक्याचे इशारे. disk, battery, तापमान, RAM, crash, virus, internet, C: drive अशा तपासण्या "आपोआप तपासा" ने tool स्वतः चालवून निकाल सोप्या भाषेत सांगतो. (Pendrive वरचे Tools / Installers folders लपवलेले आहेत - सगळे tools इथूनच वापरा.)
  • Report: customer ला देण्यासाठी HTML report. तो pendrive वरील Reports\ folder मध्ये save होतो.

5. सामान्य समस्या: काय करायचे

समस्याउपाय
PC खूप slow आहेPC Doctor → Scan → One-Click Optimize. Windows HDD वर असेल तर SSD लावा (Rescuezilla ने clone करा). RAM 8 GB करा.
C: drive भरला आहेPC Doctor → C: drive जागा → files दुसऱ्या drive वर हलवा. Speed tab मधील cleanup चालवा.
Windows सुरू होत नाही / restart loop / blue screenBoot menu → Hiren's BootCD PE → USB उघडा → PCDoctor-Rescue.cmd. आधी 8 (files वाचवा, disk खराब असल्यास), मग 3 (अडकलेले updates), 2 (blue screen चा driver), 4 (SFC), 7 (boot files). Wi-Fi नसेल तर 1 - तो त्याच PC च्या Windows मधले drivers load करतो.
Blue screenPC Doctor → Tools मार्गदर्शक → BlueScreenView → "आपोआप तपासा" (कोणता driver आणि उपाय). Boot menu मधून MemTest86+ चालवा.
Virus / ads / browser homepage बदललाTools मार्गदर्शक → Microsoft Safety Scanner (आपोआप तपासा), AdwCleaner, KVRT. फार infected असेल तर boot menu मधील Kaspersky Rescue Disk.
File delete झाली / pendrive format झालात्या drive वर काहीही नवीन लिहू नका. Recuva (Windows मध्ये) किंवा SystemRescue → PhotoRec वापरा.
Windows reinstall करायचे आहेआधी PC Doctor → दुरुस्ती → Drivers backup (आणि Tools मार्गदर्शक → ProduKey → "आपोआप तपासा" ने product key save करा). Reinstall नंतर → Drivers restore.
Drivers नाहीत (नवीन Windows नंतर)PC Doctor → दुरुस्ती → Drivers, किंवा Tools मार्गदर्शक → Snappy Driver Installer Origin. Setup करताना "offline driver packs" ला Y दिल्यास (~70 GB) internet शिवाय कोणत्याही PC चे drivers मिळतात.
Internet चालत नाहीPC Doctor → दुरुस्ती → Network reset → restart.

6. सुरक्षितता नियम

  • Partition बदलण्याआधी आणि disk clone करण्याआधी नेहमी backup घ्या. Laptop charging ला लावून ठेवा.
  • Password reset आणि data recovery फक्त मालकाच्या परवानगीने करा.
  • ShredOS आणि disk wipe tools disk कायमची पुसतात. Disk number दोनदा तपासा.
  • Cracked software किंवा activators कधीही वापरू नका. त्यांच्यासोबत बऱ्याचदा virus येतो.
टीप: सर्व tools त्यांच्या निर्मात्यांच्या official websites वरून download होतात. हे tools free आहेत. काहींचा commercial वापर (उदा. दुकानात customer PC साठी) करण्याआधी त्यांचे license तपासा.
