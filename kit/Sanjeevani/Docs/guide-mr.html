1Pendrive तयार करणे

  1. 64 GB USB 3.x pendrive घ्या (offline driver packs हवे असतील तर 256 GB). त्यातील सगळा data पुसला जाईल.
  2. Kit ची zip file extract करा (right-click → Extract All).
  3. SETUP.cmd वर double-click करा आणि Administrator परवानगी द्या.
  4. भाषा निवडा (English / मराठी / हिन्दी) - PC Doctor आणि हे मार्गदर्शक त्याच भाषेत येतात.
  5. Pendrive चा Disk number टाका, नंतर ERASE टाइप करा.
  6. Optional downloads विचारले जातील: Windows 11 ISO (7.5 GB), Linux Mint (3 GB), Assistant साठी offline AI (3.2 GB), offline driver packs (70 GB).
  7. Internet speed नुसार 30 मिनिटे ते 2 तास लागतात. काही tools हाताने download करायचे असतील तर त्यांची यादी शेवटी आपोआप उघडते.

Update: नंतर कधीही pendrive वरील Sanjeevani\Setup\UPDATE.cmd चालवा. फक्त नवीन versions download होतात आणि काहीही पुसले जात नाही.

Write-protect switch: pendrive ला lock switch असेल तर customer च्या PC वर तो lock ठेवा - virus त्यावर काहीही लिहू शकत नाही. फक्त तुमच्या स्वच्छ PC वर update करताना unlock करा. Switch नसला तरी PC Doctor प्रत्येक वेळी सुरू होताना virus ने pendrive वर केलेले बदल तपासतो.

2Pendrive वरून boot करणे

  1. PC बंद करा आणि pendrive लावा.
  2. Power दाबताच Boot Menu key दाबत राहा (HP F9, Dell F12, Lenovo F12, Asus Esc...). पूर्ण यादी boot-keys.html मध्ये आहे.
  3. संजीवनी menu दिसेल. ↑ ↓ ने tool निवडा आणि Enter दाबा. प्रत्येक tool ची माहिती खाली दिसते.
  4. Secure Boot error आला तर boot-keys.html मधील "Enroll key" पायऱ्या करा. हे एकदाच करावे लागते.

4PC Doctor (Windows चालू असताना)

Pendrive उघडा आणि START-Sanjeevani.cmd वर double-click करा (Administrator परवानगी द्या).

  • PC तपासणी: Quick Scan (2 मिनिटे) किंवा Deep Scan (system files सह). Health score, तो 100 का नाही, आणि प्रत्येक समस्येपुढे दुरुस्तीचे button.
  • One-Click Optimize: restore point → junk cleanup → अनावश्यक startup बंद → हलके effects → power plan → ads / bloatware काढणे → report.
  • दुरुस्ती: DISM + SFC (खराब system files), disk check, Windows Update reset, network reset, Defender, drivers, registry तपासणी (virus ने बदललेल्या settings).
  • वेग वाढवा: startup programs, tweaks, bloatware. सर्व बदल Undo करता येतात.
  • C: drive जागा: Desktop, Documents, Downloads, Photos आणि C:\ मधले स्वतःचे folders दुसऱ्या drive वर हलवा; दुसरा drive नसेल तर C: लहान करून DATA drive बनवा.
  • OS व Apps सल्ला: Windows 11 चालेल का, या PC ला कोणते OS योग्य, कोणते apps काढावेत आणि हलके पर्याय, RAM / SSD upgrade.
  • Tools मार्गदर्शक: 60+ tools - प्रत्येक काय करतो, कधी आणि कसा वापरायचा, इशाऱ्यांसह. "आपोआप तपासा" tool स्वतः चालवून निकाल समजावतो (disk, battery, तापमान, RAM, crash, virus, internet, C: drive). Pendrive वरचे Tools / Installers folders लपवलेले आहेत - tools इथूनच वापरा.
  • Report: customer साठी HTML report, pendrive च्या Reports\ folder मध्ये save होतो.
  • भाषा: title bar मधून English / मराठी / हिन्दी कधीही बदला.

5Assistant - समस्या सांगा, तो दुरुस्त करतो

  • समस्या स्वतःच्या शब्दांत लिहा - मराठी, हिंदी, English किंवा Roman ("net chalat nahi", "laptop खूप गरम होतो", "printer print देत नाही").
  • एकदाच परवानगी द्या. Restore point बनतो आणि मग सगळे आपोआप: Assistant समस्या समजून घेतो, ती या PC वर खरंच आहे का ते तपासतो, दुरुस्त करतो, पुन्हा तपासतो, आणि पहिले कारण ठीक असल्यास पुढच्या संभाव्य कारणाकडे जातो.
  • शेवटी थोडक्यात सांगतो: काय समस्या होती, काय केले, आणि restart लागेल का.
  • Offline AI (Gemma, pendrive वर) 6 GB+ RAM च्या PC वर internet शिवाय चालतो. Online AI optional - तुमच्या स्वतःच्या key ने (Google Gemini ची key मोफत). AI नसला तरी keywords ने 38 सामान्य समस्या ओळखतो.
  • AI कधीही स्वतः commands चालवत नाही - तो फक्त PC Doctor च्या तपासलेल्या तपासण्या आणि दुरुस्त्यांमधून निवडतो.

6स्वतःचे apps आणि दुसरे OS जोडणे

  • दुसरे OS / boot tools: .iso (किंवा .wim, .img, .vhd) pendrive च्या ISO folder मध्ये copy करा - boot menu मध्ये आपोआप दिसते (उदा. Windows 10, Ubuntu). 4 GB पेक्षा मोठी ISO पण चालते. काढायची असेल तर फाईल delete करा.
  • स्वतःचे Windows apps: portable app चा folder, एकटी .exe, installer (.exe / .msi) किंवा .zip / .7z / .rar pendrive च्या MyTools folder मध्ये ठेवा. Zip UPDATE.cmd आपोआप extract करतो, किंवा PC Doctor मध्ये "Extract करा" दाबा. ते PC Doctor → Tools मार्गदर्शक → माझे tools मध्ये दिसतात. App च्या नावाची .txt ठेवल्यास (उदा. AnyDesk.txt) पहिली ओळ वर्णन म्हणून दिसते.
  • पहिल्यांदा virus तपासणी विचारेल "हे तुम्ही स्वतः टाकले का?" - हो म्हणा म्हणजे ते नोंदवले जातील. तुम्ही न टाकलेला program दिसला तर नाही म्हणा: तो quarantine होईल.
  • Apps MyTools मध्येच ठेवा - Tools मध्ये टाकलेला नवीन program virus समजला जातो.
  • फक्त official website वरून घेतलेले, virus scan केलेले programs ठेवा.
  • Pendrive भरला? CLEAN.cmd चालवा - duplicate driver packs, जुनी versions, अर्धवट downloads आधी यादीत दाखवतो आणि तुम्ही हो म्हटल्यावरच _to_delete मध्ये हलवतो. Reports आणि Rescue (customer data) ला कधीच हात लावत नाही.

7सामान्य समस्या: काय करायचे

समस्याउपाय
कोणतीही समस्याPC Doctor → Assistant: समस्या लिहा - तो आपोआप तपासून दुरुस्त करतो.
PC खूप slowPC तपासणी → One-Click Optimize. Windows HDD वर असेल तर SSD लावा (Rescuezilla ने clone). RAM 8 GB करा.
C: drive भरलाC: drive जागा → files दुसऱ्या drive वर हलवा; "वेग वाढवा" page वर cleanup.
Windows सुरू होत नाही / restart loopBoot menu → Hiren's BootCD PE → USB उघडा → PCDoctor-Rescue.cmd: disk खराब असल्यास आधी files वाचवा, मग अडकलेले updates, blue screen चा driver, SFC, boot files. Wi-Fi नसेल तर पर्याय 1 त्याच PC च्या Windows मधले drivers load करतो.
Blue screenTools मार्गदर्शक → BlueScreenView → "आपोआप तपासा" (कोणता driver आणि उपाय). Boot menu मधून MemTest86+.
Virus / ads / homepage बदललाTools मार्गदर्शक → Microsoft Safety Scanner, AdwCleaner, KVRT; registry तपासणी. फार infected: boot menu मधील Kaspersky Rescue Disk.
File delete / pendrive formatत्या drive वर काहीही नवीन लिहू नका. Recuva (Windows मध्ये) किंवा SystemRescue → PhotoRec.

Internet चालत नाहीAssistant: "internet chalat nahi" - किंवा दुरुस्ती → Network reset → restart.

8सुरक्षितता नियम

  • Partition बदलण्याआधी आणि disk clone करण्याआधी नेहमी backup घ्या. Laptop charging ला लावून ठेवा.
  • Password reset आणि data recovery फक्त मालकाच्या परवानगीने करा.
  • ShredOS आणि disk wipe tools disk कायमची पुसतात. Disk number दोनदा तपासा.
  • Cracked software किंवा activators कधीही वापरू नका - त्यांच्यासोबत बऱ्याचदा virus येतो.
टीप: सर्व tools त्यांच्या निर्मात्यांच्या official websites वरून download होतात आणि free आहेत. Commercial वापराआधी (उदा. दुकानात customer PC साठी) प्रत्येकाचे license तपासा.
