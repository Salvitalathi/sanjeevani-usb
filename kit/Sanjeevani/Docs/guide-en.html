1Make the USB

  1. Take a 64 GB USB 3.x pendrive (256 GB for the offline driver packs). Everything on it will be erased.
  2. Extract the kit zip (right-click → Extract All).
  3. Double-click SETUP.cmd and allow Administrator.
  4. Choose the language (English / मराठी / हिन्दी) - PC Doctor and this guide use it.
  5. Type the pendrive's Disk number, then type ERASE.
  6. Answer the optional downloads: Windows 11 ISO (7.5 GB), Linux Mint (3 GB), offline AI for the Assistant (3.2 GB), offline driver packs (70 GB).
  7. It takes 30 minutes to 2 hours depending on the internet. If some tool needs a manual download, its list opens by itself at the end.

Update: run Sanjeevani\Setup\UPDATE.cmd on the USB at any time. Only newer versions are downloaded; nothing is erased.

Write-protect switch: if the pendrive has a lock switch, keep it locked on customers' PCs - viruses cannot write to it. Unlock it only on your own clean PC for updates. Even without a switch, PC Doctor checks the USB for changes made by viruses every time it starts.

2Boot from the USB

  1. Switch the PC off and plug in the pendrive.
  2. Press the Boot Menu key right after pressing power (HP F9, Dell F12, Lenovo F12, Asus Esc ...). Full list: boot-keys.html.
  3. The Sanjeevani menu appears. Choose a tool with ↑ ↓ and press Enter; a short description shows below.
  4. If a Secure Boot error appears, follow the "Enroll key" steps in boot-keys.html - needed only once.

4PC Doctor (inside Windows)

Open the USB and double-click START-Sanjeevani.cmd (allow Administrator).

  • Health Check: Quick Scan (2 minutes) or Deep Scan (with system files). Shows a health score, why it is not 100 and a fix button next to every finding.
  • One-Click Optimize: restore point → junk cleanup → unneeded startup off → lighter effects → power plan → ads / bloatware removed → report.
  • Repair: DISM + SFC (damaged system files), disk check, Windows Update reset, network reset, Defender, drivers, registry check (settings changed by viruses).
  • Speed Up: startup programs, tweaks, bloatware. Every change can be undone.
  • Disk Space: move Desktop, Documents, Downloads, Photos and your own folders in C:\ to another drive; without a second drive, shrink C: and create a DATA drive.
  • OS & Apps Advice: does Windows 11 fit, which OS suits this PC, which apps to remove and lighter alternatives, RAM / SSD upgrades.
  • Tools Guide: 60+ tools - what each does, when and how to use it, with warnings. "Check automatically" runs the tool and explains the result (disk, battery, temperature, RAM, crashes, viruses, internet, C: drive). The raw Tools / Installers folders on the USB are hidden - use the tools from here.
  • Report: an HTML report for the customer, saved in the USB's Reports\ folder.
  • Language: switch English / मराठी / हिन्दी in the title bar at any time.

5Assistant - describe the problem, it fixes it

  • Type the problem in your own words - English, Marathi, Hindi or Roman script ("net nahi chal raha", "laptop खूप गरम होतो", "printer not printing").
  • You allow it once. A restore point is made, then everything is automatic: the Assistant understands the problem, checks whether it really exists on this PC, fixes it, checks again, and moves on to the next likely cause if the first one was fine.
  • At the end it tells you briefly what the issue was, what was done and whether a restart is needed.
  • Offline AI (Gemma, on the USB) works without internet on PCs with 6 GB+ RAM. Online AI is optional with your own key (Google Gemini keys are free). Without AI it still understands 38 common problems by keywords.
  • The AI never runs commands - it only picks from PC Doctor's own tested checks and repairs.

6Adding your own apps and other OSes

  • Other OS / boot tools: copy the .iso (or .wim, .img, .vhd) to the USB's ISO folder - it appears in the boot menu by itself (e.g. Windows 10, Ubuntu). ISOs over 4 GB work too. Delete the file to remove it.
  • Your Windows apps: put a portable app's folder, a single .exe, an installer (.exe / .msi) or a .zip / .7z / .rar in the USB's MyTools folder. Zips are extracted by UPDATE.cmd, or press "Extract" in PC Doctor. They appear in PC Doctor → Tools Guide → My tools. A .txt with the app's name (e.g. AnyDesk.txt) - its first line is shown as the description.
  • The first time, the virus check asks "Did you put these here yourself?" - answer Yes so they are recorded. If you see a program you did not add, answer No: it is quarantined.
  • Keep apps in MyTools only - a new program inside Tools is treated as a virus.
  • Use only programs from official websites, virus-scanned.
  • USB full? Run CLEAN.cmd - it lists duplicate driver packs, old versions and partial downloads first and moves them to _to_delete only after you agree. It never touches Reports or Rescue (customer data).

8Safety rules

  • Always back up before changing partitions or cloning a disk. Keep the laptop on the charger.
  • Password resets and data recovery only with the owner's permission.
  • ShredOS and disk-wipe tools erase a disk for good. Check the disk number twice.
  • Never use cracked software or activators - they often carry malware.
Note: every tool is downloaded from its maker's official website and is free. Check each licence before commercial use (e.g. on customers' PCs in a shop).
