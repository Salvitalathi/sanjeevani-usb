Windows मधून थेट: Shift धरून Restart → Troubleshoot → Advanced options → UEFI Firmware Settings. किंवा "Use a device" → USB.
Secure Boot error (Verification failed / Security violation): पहिल्यांदा Ventoy boot होताना blue screen आल्यास → Enroll key from disk → VTOYEFI → ENROLL_THIS_KEY_IN_MOKMANAGER.cer → Continue → Yes → Reboot. एकदाच करावे लागते. किंवा BIOS मध्ये Secure Boot तात्पुरता Disable करा.
USB दिसत नाही? दुसऱ्या USB port (मागचा / USB 2.0) मध्ये लावा. BIOS मध्ये "Fast Boot" Off करा. फार जुन्या PC वर "Legacy / CSM" On करा.
