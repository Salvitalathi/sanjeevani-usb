1Pendrive बनाना

  1. 64 GB USB 3.x pendrive लें (offline driver packs चाहिए तो 256 GB)। उसका सारा data मिट जाएगा।
  2. Kit की zip file extract करें (right-click → Extract All)।
  3. SETUP.cmd पर double-click करें और Administrator अनुमति दें।
  4. भाषा चुनें (English / मराठी / हिन्दी) - PC Doctor और यह गाइड उसी भाषा में आते हैं।
  5. Pendrive का Disk number लिखें, फिर ERASE टाइप करें।
  6. Optional downloads पूछे जाएँगे: Windows 11 ISO (7.5 GB), Linux Mint (3 GB), Assistant के लिए offline AI (3.2 GB), offline driver packs (70 GB)।
  7. Internet speed के अनुसार 30 मिनट से 2 घंटे लगते हैं। कुछ tools हाथ से download करने हों तो उनकी सूची आख़िर में अपने आप खुलती है।

Update: बाद में कभी भी pendrive पर Sanjeevani\Setup\UPDATE.cmd चलाएँ। सिर्फ़ नए versions download होते हैं, कुछ नहीं मिटता।

Write-protect switch: pendrive में lock switch हो तो customer के PC पर उसे lock रखें - virus उस पर कुछ नहीं लिख सकता। सिर्फ़ अपने साफ़ PC पर update करते समय unlock करें। Switch न हो तो भी PC Doctor हर बार शुरू होते समय virus द्वारा pendrive पर किए बदलाव जाँचता है।

2Pendrive से boot करना

  1. PC बंद करें और pendrive लगाएँ।
  2. Power दबाते ही Boot Menu key दबाते रहें (HP F9, Dell F12, Lenovo F12, Asus Esc...)। पूरी सूची boot-keys.html में है।
  3. संजीवनी menu दिखेगा। ↑ ↓ से tool चुनें और Enter दबाएँ। हर tool की जानकारी नीचे दिखती है।
  4. Secure Boot error आए तो boot-keys.html के "Enroll key" कदम करें। यह एक ही बार करना होता है।

4PC Doctor (Windows चालू होने पर)

Pendrive खोलें और START-Sanjeevani.cmd पर double-click करें (Administrator अनुमति दें)।

  • PC जाँच: Quick Scan (2 मिनट) या Deep Scan (system files सहित)। Health score, वह 100 क्यों नहीं, और हर समस्या के सामने मरम्मत का button.
  • One-Click Optimize: restore point → junk cleanup → बेकार startup बंद → हल्के effects → power plan → ads / bloatware हटाना → report.
  • मरम्मत: DISM + SFC (खराब system files), disk check, Windows Update reset, network reset, Defender, drivers, registry जाँच (virus द्वारा बदली settings)।
  • स्पीड बढ़ाएँ: startup programs, tweaks, bloatware. सभी बदलाव Undo हो सकते हैं।
  • C: drive जगह: Desktop, Documents, Downloads, Photos और C:\ के अपने folders दूसरे drive पर ले जाएँ; दूसरा drive न हो तो C: छोटा करके DATA drive बनाएँ।
  • OS और Apps सलाह: Windows 11 चलेगा या नहीं, इस PC के लिए कौन सा OS सही, कौन से apps हटाएँ और हल्के विकल्प, RAM / SSD upgrade.
  • Tools गाइड: 60+ tools - हर एक क्या करता है, कब और कैसे इस्तेमाल करें, चेतावनियों के साथ। "अपने आप जाँचें" tool खुद चलाकर नतीजा समझाता है (disk, battery, तापमान, RAM, crash, virus, internet, C: drive)। Pendrive के Tools / Installers folders छिपे हैं - tools यहीं से इस्तेमाल करें।
  • Report: customer के लिए HTML report, pendrive के Reports\ folder में save होती है।
  • भाषा: title bar से English / मराठी / हिन्दी कभी भी बदलें।

5Assistant - समस्या बताइए, वह ठीक करता है

  • समस्या अपने शब्दों में लिखें - हिंदी, मराठी, English या Roman ("net nahi chal raha", "laptop बहुत गर्म होता है", "printer print नहीं कर रहा")।
  • एक बार अनुमति दें। Restore point बनता है और फिर सब अपने आप: Assistant समस्या समझता है, जाँचता है कि वह इस PC पर सच में है या नहीं, ठीक करता है, फिर से जाँचता है, और पहला कारण ठीक हो तो अगले संभावित कारण पर जाता है।
  • आख़िर में थोड़े में बताता है: क्या समस्या थी, क्या किया, और restart चाहिए या नहीं।
  • Offline AI (Gemma, pendrive पर) 6 GB+ RAM वाले PC पर बिना internet चलता है। Online AI optional - अपनी key से (Google Gemini की key मुफ़्त)। AI न हो तो भी keywords से 38 आम समस्याएँ पहचानता है।
  • AI कभी खुद commands नहीं चलाता - वह सिर्फ़ PC Doctor की जाँची हुई जाँचों और मरम्मतों में से चुनता है।

6अपने apps और दूसरे OS जोड़ना

  • दूसरे OS / boot tools: .iso (या .wim, .img, .vhd) pendrive के ISO folder में copy करें - boot menu में अपने आप दिखता है (जैसे Windows 10, Ubuntu)। 4 GB से बड़ी ISO भी चलती है। हटाना हो तो file delete करें।
  • अपने Windows apps: portable app का folder, अकेली .exe, installer (.exe / .msi) या .zip / .7z / .rar pendrive के MyTools folder में रखें। Zip को UPDATE.cmd अपने आप extract करता है, या PC Doctor में "Extract करें" दबाएँ। वे PC Doctor → Tools गाइड → मेरे tools में दिखते हैं। App के नाम की .txt रखें (जैसे AnyDesk.txt) तो पहली line विवरण के रूप में दिखती है।
  • पहली बार virus जाँच पूछेगी "क्या ये आपने खुद रखे हैं?" - हाँ कहें ताकि वे दर्ज हों। आपने न रखा program दिखे तो नहीं कहें: वह quarantine होगा।
  • Apps सिर्फ़ MyTools में रखें - Tools में रखा नया program virus माना जाता है।
  • सिर्फ़ official website से लिए, virus scan किए programs रखें।
  • Pendrive भर गया? CLEAN.cmd चलाएँ - duplicate driver packs, पुराने versions और अधूरे downloads पहले सूची में दिखाता है और आपकी हाँ के बाद ही _to_delete में ले जाता है। Reports और Rescue (customer data) को कभी नहीं छूता।

7आम समस्याएँ: क्या करें

समस्याउपाय
कोई भी समस्याPC Doctor → Assistant: समस्या लिखें - वह अपने आप जाँचकर ठीक करता है।
PC बहुत slowPC जाँच → One-Click Optimize. Windows HDD पर हो तो SSD लगाएँ (Rescuezilla से clone)। RAM 8 GB करें।
C: drive भर गयाC: drive जगह → files दूसरे drive पर ले जाएँ; "स्पीड बढ़ाएँ" page पर cleanup.
Windows शुरू नहीं होता / restart loopBoot menu → Hiren's BootCD PE → USB खोलें → PCDoctor-Rescue.cmd: disk खराब हो तो पहले files बचाएँ, फिर अटके updates, blue screen का driver, SFC, boot files. Wi-Fi नहीं? विकल्प 1 उसी PC के Windows से drivers load करता है।
Blue screenTools गाइड → BlueScreenView → "अपने आप जाँचें" (कौन सा driver और उपाय)। Boot menu से MemTest86+.
Virus / ads / homepage बदलाTools गाइड → Microsoft Safety Scanner, AdwCleaner, KVRT; registry जाँच। बहुत infected: boot menu का Kaspersky Rescue Disk.
File delete / pendrive formatउस drive पर कुछ भी नया न लिखें। Recuva (Windows में) या SystemRescue → PhotoRec.
Windows reinstallपहले मरम्मत → Drivers backup और Tools गाइड → ProduKey (product key save)। Reinstall के बाद → Drivers restore.
Internet नहीं चल रहाAssistant: "internet nahi chal raha" - या मरम्मत → Network reset → restart.

8सुरक्षा नियम

  • Partition बदलने और disk clone करने से पहले हमेशा backup लें। Laptop को charger पर रखें।
  • Password reset और data recovery सिर्फ़ मालिक की अनुमति से करें।
  • ShredOS और disk wipe tools disk हमेशा के लिए मिटाते हैं। Disk number दो बार जाँचें।
  • Cracked software या activators कभी इस्तेमाल न करें - उनके साथ अक्सर virus आता है।
नोट: सभी tools अपने निर्माताओं की official websites से download होते हैं और free हैं। Commercial इस्तेमाल से पहले (जैसे दुकान में customer PC के लिए) हर एक का license जाँचें।
