संजीवनी RESCUE USB
==================
एक pendrive पर free और legal toolkit: rescue tools का boot menu + PC Doctor
(PC जाँच, अपने आप मरम्मत, स्पीड बढ़ाना, Assistant). English / मराठी / हिन्दी.

Pendrive बनाना
1. यह zip extract करें (right-click > Extract All).
2. 64 GB pendrive लगाएँ (offline driver packs चाहिए तो 256 GB).
   उसका सारा DATA मिट जाएगा।
3. SETUP.cmd पर double-click करें और Administrator अनुमति दें।
4. भाषा चुनें (English / मराठी / हिन्दी).
5. Pendrive का Disk number लिखें, फिर ERASE टाइप करें।
6. Downloads होने दें (internet के अनुसार 30 मिनट से 2 घंटे).

इस्तेमाल
- Windows में: USB खोलें और START-Sanjeevani.cmd पर double-click करें (PC Doctor).
  Assistant में समस्या लिखें - वह PC जाँचकर अपने आप ठीक करता है।
- Windows शुरू न हो: Boot Menu key (F12 / F9 / Esc ...) दबाकर USB चुनें,
  फिर Hiren's BootCD PE > PCDoctor-Rescue.cmd.
- पूरी गाइड: USB पर "READ-ME - गाइड.html" (kit\Sanjeevani\Docs\guide-hi.html).

बाद में
- Update:  <USB>\Sanjeevani\Setup\UPDATE.cmd
- Pendrive भर गया: CLEAN.cmd (पहले सूची दिखाता है, आपकी हाँ के बाद ही हटाता है)
- अपने apps: <USB>\MyTools में copy करें    दूसरे OS / ISO files: <USB>\ISO

USB के folders
  ventoy\        boot menu theme + ventoy.json
  ISO\           bootable rescue images (अपनी .iso यहाँ रखें)
  Tools\         portable Windows tools (छिपे हुए - PC Doctor की Tools गाइड से इस्तेमाल करें)
  Installers\    installers (7-Zip, Malwarebytes ...) (छिपे हुए)
  MyTools\       आपके अपने apps
  Sanjeevani\    PC Doctor, docs, tools सूची, setup
  Reports\       PC Doctor reports (हर PC का अलग folder)
